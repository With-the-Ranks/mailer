# Get Started

Advanced guides for power users who want to customize Mailer to their needs.

## Email Providers

Mailer supports multiple email providers:

- **[AWS SES Integration](./advanced-users/ses-integration)** - Default provider with scalable, reliable delivery
- **[Resend Integration](./advanced-users/resend-integration)** - Alternative provider with simple setup

## Provider Comparison

| Feature | AWS SES (Default) | Resend |
|---------|-------------------|--------|
| Setup complexity | Moderate | Easy |
| Deliverability | Excellent | Excellent |
| Analytics | Via webhooks | Built-in dashboard |
| Best for | Production deployments | Quick prototyping |
